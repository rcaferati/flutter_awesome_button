# rcaferati_flutter_awesome_button example

This example app mirrors the React Native demo structure with three main flows:

- `Themed Buttons`
- `Progress`
- `Social`

It also includes nested theme navigation, character art, text-transition demos, empty placeholders, and the social/progress sections from the RN gallery.

The social gallery uses canonical `ButtonVariant.x`; progress includes a
`showProgressBar: false` example. This app is a manual showcase and build
surface. Automated behavior coverage belongs to the package `test/` directory,
not to demo UI tests or application test targets.

From the package root:

```bash
cd example
flutter run
```
