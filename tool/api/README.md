# Public API baseline

`current.json` is generated by `dart_apitool` 0.23.2 from the package source and is reviewed as part of every intentional public API change. `tool/check-api-model.sh` regenerates the model in secure temporary storage and fails when the normalized semantic JSON differs.

The baseline was first generated on 2026-08-30 with Flutter 3.41.7 (`cc0734ac71`) and Dart 3.11.5, then reviewed for the 0.10.0 release. The package version stored in `current.json` must match the release source while declaration changes remain governed by the versioned semantic comparison.

The tool is intentionally isolated under `tool/dart_apitool`: its Analyzer
dependency cannot coexist with Flutter 3.41.7's pinned SDK dependencies in the
library's root resolution. Both manifests and lockfiles are immutable CI inputs.
